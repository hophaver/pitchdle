# Pitchdle: 75-second demo video

A short feature demo, cut from the longer [video-script.md](video-script.md). About 180 spoken words. Footage is
recorded from Demo mode and lives in `docs/demo-footage/` (1600×900, silent).

TideLedger's crowd score moves with how many demo answers there are (the footage shows 2.7), so the voiceover
doesn't quote it. The evidence score (1.7) and the call (Avoid) are fixed.
